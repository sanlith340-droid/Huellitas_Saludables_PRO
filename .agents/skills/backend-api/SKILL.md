# Skill: backend API

Leer primero `AGENTS.md`, las Rules de arquitectura, seguridad y documentación, y la bitácora relacionada.

## Flujo

1. Localizar ruta, controlador, servicio, modelo, esquema y pruebas relacionados.
2. Definir autenticación, roles, validación y respuestas de error.
3. Mantener la lógica de negocio en servicios.
4. Actualizar Swagger y `DOCS_PROYECTO/back_DOCUMENTACION/API.md` cuando cambie la API.
5. Crear pruebas de éxito, validación, permisos y errores.
6. Ejecutar `cd back && npm test` y registrar el resultado.
7. Actualizar la bitácora y `ESTADO_ACTUAL.md`.

No crear un backend paralelo en la raíz.
