# Skill: Prisma y base de datos

1. Leer `AGENTS.md`, las Rules de arquitectura y seguridad, y la documentación de base de datos.
2. Revisar el esquema y las migraciones existentes antes de cambiarlo.
3. Crear una nueva migración; no editar migraciones ya aplicadas.
4. Revisar SQL, relaciones, índices, nulabilidad y claves foráneas.
5. Probar en base vacía y base existente cuando el cambio sea relevante.
6. Actualizar servicios, pruebas y documentación.
7. Registrar comandos y resultados en la bitácora.
