# Skill: frontend React

Leer primero `AGENTS.md`, las Rules de arquitectura y documentación, y la documentación de interfaz relacionada.

## Flujo

1. Revisar rutas, autenticación y roles existentes.
2. Reutilizar componentes y estilos antes de crear duplicados.
3. Implementar estados de carga, error, vacío y éxito.
4. No confiar en restricciones visuales para seguridad.
5. Actualizar `DOCS_PROYECTO/front_DOCUMENTACION/`.
6. Ejecutar `cd front && npm run build`.
7. Registrar resultado, capturas si aplican y pendientes.
