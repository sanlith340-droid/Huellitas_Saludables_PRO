# Workflow: cierre y entrega a otro modelo

Antes de terminar una sesión:

1. Revisar `git diff` o la lista de archivos modificados.
2. Ejecutar las pruebas aplicables.
3. Registrar resultados reales en la bitácora.
4. Actualizar `.agents/workflows/ESTADO_ACTUAL.md`.
5. Escribir el siguiente paso concreto.
6. Indicar bloqueos, riesgos y decisiones pendientes.
7. Confirmar que el próximo modelo puede empezar leyendo `AGENTS.md` sin depender del chat.
